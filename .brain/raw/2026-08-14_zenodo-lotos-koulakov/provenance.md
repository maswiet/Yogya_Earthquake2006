## Description (as published)

Full version of the LOTOS code with initial data and parameters used for
calculating P and S velocity models beneath the Gakkel Ridge (~85E), adapted for
a mobile seismic network on Arctic ice floes (adds a constant-velocity water
layer). Windows build (Microsoft Visual Studio 2010, Intel Visual Fortran).
Supports Koulakov et al. "Low-degree mantle melting controls deep seismicity and
explosive volcanism of the Gakkel Ridge."

## Relevance note (not part of the source)

This is the Arctic/Gakkel-Ridge application of LOTOS by its author. LOTOS (Koulakov
2009) is the SAME tomography engine (LOTOS-13) used by our group in Diambama et
al. 2019 for the Yogyakarta 2006 tomography. Captured as a reference to the code
itself, not as Yogyakarta data.
